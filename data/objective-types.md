## 类型说明

靠少数类型加参数，不靠每个故事写一套脚本。同一类型可挂到不同节点的不同文案上。

| 类型 | 程序名（草案） | 本场怎样算完成 | 典型用法 |
|------|----------------|----------------|----------|
| 突击撕口 | `assault` | 撕开指定突破线，或控制指定点一段时间 | 夜突撕口、攻城/城郊、抢渡口、夺桥、对岸巩固 |
| 护渡/过点 | `escort` | 指定人员或物资到达指定区域 | 掩护辎重、掩护半渡、把人送过河、护粮 |
| 断后坚持 | `rear_guard` | 坚持指定时间，或直到友军脱离标记成立 | 阻击换脱离、河岸阻击、断后最后撤、渡后阻击、营地夜守 |
| 调开脱身 | `breakaway` | 甩掉或诱开敌军，而不是歼灭（例如坚持到某部离开，或护送到点后脱离） | 四渡「调开敌军」、渡后脱离 |
| 行军消耗 | `march` | 把指定人员带到终点，并管住粮食、伤员、掉队等消耗；战斗不是主轴 | 雪山、草地 |

说明：

- `breakaway`（调开脱身）和 `march`（行军消耗）是本次规划补上的类型，总纲原表只有 `assault` / `rear_guard` / `escort` / `night_pass`。
- `night_pass` 暂不单开一类，先当作突击撕口的夜间参数（例如出发的夜突撕口）。
- 遵义的「停攻/改道」先作为突击撕口的一种结束方式，不单开类型。
- 大渡河「对岸巩固反冲击」沿用突击撕口的守点参数，不新开类型。
- 四渡「调开敌军」的摘抄仍待补，类型先挂上，不写死番号和路线。
- 泸定桥属通行叙事、有争议，类型可挂突击撕口，细节不写死。

## 按节点标注（可以池全部标类型）

### 1. 出发 / 突破封锁

建议本场主类型：**突击撕口**

- 夜突撕口子＋掩护 → 突击撕口（夜间）
- 掩护机关辎重 → 护渡/过点
- 阻击追兵换脱离 → 断后坚持

### 2. 湘江战役（不怕牺牲）

建议本场主类型：**断后坚持**

- 河岸/渡口阻击 → 断后坚持
- 撕开封锁一角 → 突击撕口
- 断后最后撤 → 断后坚持
- 主故事「掩护主力过江」「谁断后」都挂在断后坚持上；战后点名是结算，不另开类型

### 3. 遵义一带

建议本场主类型：**突击撕口**（可中途停攻）

- 攻城/城郊 → 突击撕口（停攻令作为本类的一种结束方式）
- 掩护机关转移 → 护渡/过点
- 新路线遭遇（改道） → 突击撕口（遭遇，也可以脱离结束）

### 4. 四渡赤水

建议本场主类型：**调开脱身**；渡河那一拍用护渡/过点

- 抢渡口 → 突击撕口
- 掩护半渡 → 护渡/过点
- 渡后阻击 → 断后坚持
- 渡后脱离，以及主故事「调开敌军」 → 调开脱身

### 5. 大渡河 / 桥

建议本场主类型：**护渡/过点**

- 强渡抢滩（安顺场） → 突击撕口；若重点是把人送过河，可改挂护渡/过点
- 夺桥突击（通行叙事，有争议） → 突击撕口
- 对岸巩固反冲击 → 突击撕口（守住对岸一段时间）

### 6. 雪山

建议本场主类型：**行军消耗**

- 环境伤害为主、跟上队伍 → 行军消耗
- 护粮过山 → 护渡/过点
- 山口遭遇 → 突击撕口（偏轻，只作穿插）

### 7. 草地

建议本场主类型：**行军消耗**

- 饥饿与补给、有限资源 → 行军消耗
- 护粮 → 护渡/过点
- 边缘遭遇 → 突击撕口（偏轻）
- 营地夜扰 → 断后坚持（守营）

## 若只走每场建议主类型，节奏会是

先学会撕口，再在湘江付代价断后，遵义仍是进攻但可以停，四渡改成「走掉就算赢」，大渡河把人送过河，最后两场变成分配和消耗。四种战斗类型都会用到，也不会一场里同时教三种。

可以池里有的节点会同时出现两三种类型，那是选项，不是一场里全做。
