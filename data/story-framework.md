# 长征游戏 · 故事框架 v0（「可以」池）

更新：2026-11-09；配图补充：2026-11-25（上海时区）  
用途：按已勾「可以」的候选搭**可用故事框架**，供玩法/系统对着设计；**不是**史实定稿，标待核处仍待回书核对。  
规则：改编只用班排视角；不新增无出处情节。泸定桥等标「通行叙事／有争议」。  
配图规则：只放许可可核对的路线图、今人示意图或地点环境照；**不是**交火现场照。图注写明性质；找不到可靠出处就不放。湘江节点目前没有可核对的自由许可现场/环境图，故不配图。

出处简称：斯诺｜索尔兹伯里｜王树增｜《红军长征记》｜孙书云｜Young

---

## 总结构

七个地理大/战役节点；每点：**主战斗 + 主故事**（本框架保留「可以」多选项作池）+ 穿插小任务。  
叙事驱动设想：士兵数据（士气/经历/成长）× 时空环境 × 行动前资源分配 × 战术按钮。

配套系统草稿（本地 `GamePlay/`，本页仅点名）：
- 士兵最小版：hp / morale / traits / tags / bond / storySeed；R1 减员士气、R2 低士气犹豫、R3 经历复用
- 战术按钮优先：掩护射击、尖刀组、迂回、断后掩护
- 行动前资源：ammo / food / med / tool → 分到士兵 loadout

设计注（来自勾选边批）：
- 战士各有故事，可在不同节点挖出；**牺牲则个人故事永久消失**
- 遵义：错误进攻中途收到停攻令时的抉择
- 四渡：强调士气；「调开敌军」需要摘抄支撑
- 草地/行动前：资源分配本身就是叙事

## 1. 出发 / 突破封锁

**主故事池（可以）**
- A 伤员与突围取舍（索尔兹伯里等突围通行话题）
- B 突破封锁线中一次夜间掩护（突围通行叙事）
- C 女战士随队出发的个人理由（Young / 斯诺口述传统）

**主战斗池（可以）**  
夜突撕口子＋掩护｜掩护机关辎重｜阻击追兵换脱离

**小任务池（可以）**  
告别与信物｜女红军入伍短谈｜逃兵/掉队侧影（孙书云传统）

**系统挂钩（草案）**  
资源：弹药偏掩护；药品偏伤员线。按钮：掩护、断后。tag：`突围`。

---

## 2. 湘江战役（不怕牺牲）

**主故事池（可以）**
- A 掩护主力过江的代价
- B 渡江次序与谁断后（落在具体人名）
- C 战后点名：满员→残缺（个人故事可永久消失）

**主战斗池（可以）**  
河岸/渡口阻击｜撕开封锁一角｜断后最后撤

**小任务池（可以）**  
战前遗书/托付｜伤员过江 vs 丢下｜战后点名收遗物

**系统挂钩**  
高压 R1；断后目标＋弹药药品；按钮：断后、掩护、尖刀。

---

## 3. 遵义一带

**主故事池**
- A 上层改线，下层只收到新命令；**可含「错误进攻中途停攻令」抉择**（可以）
- B 街巷/城郊战斗记忆（可以）
- C 路线突变纪律危机（**待核**，未入本框架正文）

**主战斗池（可以）**  
攻城/城郊｜掩护机关转移｜新路线遭遇（改道）

**小任务池（可以）**  
打听会上定了什么｜解释不打某城｜向导/群众工作片段

**系统挂钩**  
信息 tag：`改道` `缺情报`；抉择改 morale / bond。

## 4. 四渡赤水

**主故事池（可以）**
- A 「又要渡」：疲惫与士气（需 morale）
- B 抢渡/护渡：门板船只与渡口
- C 渡后反机动配合调敌（**需摘抄**，待补）

**主战斗池（可以）**  
抢渡口｜掩护半渡｜渡后阻击或脱离

**小任务池**  
护送伤员过河｜识破恐慌传言（可以）；筹集门板（**待核**）

**系统挂钩**  
重复行动扣 morale；food；按钮：掩护、轻装急行（二期）。

## 5. 大渡河 / 桥

**主故事池**
- A 安顺场强渡（可以；「防炸船」待核）
- B 泸定桥夺桥（可以／**通行叙事有争议**）— 班排作掩护组
- C 桥战前后恐惧口述（**待核**）

**主战斗池（可以）**  
强渡抢滩｜夺桥突击（争议细节）｜对岸巩固反冲击

**小任务池**  
筹备器材（可以）；恐惧口述、彝海余波（**待核**）

**系统挂钩**  
尖刀＋掩护；高伤亡风险；争议内容 UI 可标「通行叙事」。
