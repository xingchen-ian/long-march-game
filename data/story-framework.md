# 长征游戏 · 故事框架 v0（「可以」池）

更新：2026-11-09  
用途：按已勾「可以」的候选搭**可用故事框架**，供玩法/系统对着设计；**不是**史实定稿，标待核处仍待回书核对。  
规则：改编只用班排视角；不新增无出处情节。泸定桥等标「通行叙事／有争议」。

出处简称：斯诺｜索尔兹伯里｜王树增｜《红军长征记》｜孙书云｜Young

---

## 总结构

七个地理大/战役节点；每点：**主战斗 + 主故事**（本框架保留「可以」多选项作池）+ 穿插小任务。  
叙事驱动设想：士兵数据（士气/经历/成长）× 时空环境 × 行动前资源分配 × 战术按钮。

配套系统草稿（本地 `GamePlay/`，本页仅点名）：
- 士兵最小版：hp / morale / traits / tags / bond / storySeed；R1 减员士气、R2 低士气犹豫、R3 经历复用
- 战术按钮优先：掩护射击、尖刀组、迂回、断后掩护
- 行动前资源：ammo / food / med / tool → 分到士兵 loadout

设计注（来自勾选边批）：
- 战士各有故事，可在不同节点挖出；**牺牲则个人故事永久消失**
- 遵义：错误进攻中途收到停攻令时的抉择
- 四渡：强调士气；「调开敌军」需要摘抄支撑
- 草地/行动前：资源分配本身就是叙事

## 1. 出发 / 突破封锁

**主故事池（可以）**
- A 伤员与突围取舍（索尔兹伯里等突围通行话题）
- B 突破封锁线中一次夜间掩护（突围通行叙事）
- C 女战士随队出发的个人理由（Young / 斯诺口述传统）

**主战斗池（可以）**  
夜突撕口子＋掩护｜掩护机关辎重｜阻击追兵换脱离

**小任务池（可以）**  
告别与信物｜女红军入伍短谈｜逃兵/掉队侧影（孙书云传统）

**系统挂钩（草案）**  
资源：弹药偏掩护；药品偏伤员线。按钮：掩护、断后。tag：`突围`。
