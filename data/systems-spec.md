## 1. 设计核（一句话）

玩家以班排视角指挥长征小队：行动前**分配资源**、行动中用**战术按钮**，士兵用少数字段成长与受伤；**故事事件卡**由士兵状态 × 节点时空 × 分配 × 战术触发。牺牲则该战士个人故事永久消失。

## 3. 数据

### 3.1 士兵（最小字段）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 稳定编号 |
| `name` | string | 显示名 |
| `alive` | bool | 存活 |
| `hp` | 0–100 | ≤0 → 阵亡 |
| `morale` | 0–100 | 士气 |
| `traits` | string[] | 性格短标签 |
| `tags` | string[] | 经历/状态（事件写入） |
| `bond` | 0–100 | 对小队羁绊（v0 全队共用一份可简化） |
| `storySeed` | string | 一句出身/心愿（待核可标） |
| `loadout` | 临时 | 本场 `{ammo,food,med,tool}`，行动前写入 |

**v0 不做**：武器熟练、等级树、关系网矩阵、伤病部位。

### 3.2 小队汇总（算出，不手填）

- `squadAlive`、`squadMorale`（存活平均）、`squadTags`（并集）

### 3.3 资源池（小队共享）

`ammo`｜`food`｜`med`｜`tool`（tool 按节点开放）  
节点可增减；缺省不自动回满。

### 3.4 本场目标（单选）

| id | 含义 | 分配倾向 |
|----|------|----------|
| `assault` | 强攻 | ammo → 尖刀 |
| `rear_guard` | 断后 | ammo + med → 留下的人 |
| `escort` | 护送伤员 | med + food |
| `night_pass` | 夜行通过 | food；少分 ammo |

### 3.5 节点 / 环境标签（供条件）

例：`envTags`：`湘江` `渡河` `雪山` `沼泽` `缺粮`；时间：`夜` `昼`。  
与故事框架七节点对齐，不在此重复剧情。

## 4. 规则

### 4.1 士兵规则

- **R1 减员震士气**：任一人阵亡 → 其余 `morale -= 8`（≥0）；写入 tag `失同伴`；可播叙事卡  
- **R2 低士气犹豫**：危险行动前若 `morale < 30` → 犹豫（延迟/不上前）；旁有 `bond > 70` 同伴可免一次  
- **R3 经历复用**：节点 need 某 tag 时，优先抽中带该 tag 的存活者发言/做任务

### 4.2 分配约束

- 分配总和 ≤ 池子；不能超发  
- 战术键 `need` 不满足则禁用  
- 目标与分配严重错配 → 可选士气惩罚或事件卡  
- v0 回收：未用 ammo 回池 50%；其余规则后定

### 4.3 战术按钮（优先 4 键）

| 键 | 效果草案 | 典型 need | 士兵挂钩 |
|----|----------|-----------|----------|
| 掩护射击 | 部分压制、他人机动；暴露↑ | ammo | R2 |
| 尖刀组 | 2–3 人前插；伤亡风险高 | ammo 优先 | tag `突击`；阵亡走 R1 |
| 迂回 | 绕侧耗时换夹击 | food/时间 | 成功可 +bond |
| 断后掩护 | 指定班迟滞 | ammo + med | 高压；易 `失同伴` |

第二批（未排期）：夜行肃静、伏击展开、轻装急行、收容掉队。  
队形仅两档：疏开 / 集结。

### 4.4 叙事挂钩（不做平行剧本树）

事件卡统一：`need`（目标、loadout、env、tags、morale…）→ `text` → `effect`（改 hp/morale/tags/bond）。  
来源：`Stories/story-options-by-node.md` 中「可以」池 → 故事框架 → 再拆卡。  
`storySeed` 只定开口气质；**战士阵亡 → 其个人故事永久消失**。

驱动式：

```
士兵状态 × 节点时空 × 行动前分配 × 战术按钮 → 事件卡
```

## 5. 行动循环（一局切片）

1. 进入节点 / 遭遇  
2. 选本场目标 → 看资源池 → 分配到士兵 → 确认 loadout  
3. 可播一句短叙事（发子弹/点名）  
4. 行动中：移动 + 战术键 + 队形  
5. 满足 need 时抽事件卡；结算 effect（含 R1–R3）  
6. 结束：回收规则；写入长期 tags；清空或归档 loadout

## 6.5 本场目标 · 程序挂法（v0）

**靠少数目标类型 + 参数，不靠「每个故事写一套脚本」。**  
故事框架只选/填类型与参数；胜负检查共用。

### 类型表（与 §3.4 对齐）

| type | 胜条件（共享检查器） | 常见参数 | 败/中止（可选） |
|------|----------------------|----------|-----------------|
| `assault` | 指定点被我方控制持续 `holdSec`，或撕开 `breachLine` | `pointId` / `holdSec` / `breachLine` | 尖刀全灭且未破线 |
| `rear_guard` | 坚持 `durationSec` 或直到友军标记 `allySafe` | `durationSec`、`allySafeFlag` | 断后班提前全灭 |
| `escort` | 指定单位/伤员到达 `zoneId` | `escortIds[]`、`zoneId` | 护送目标阵亡 |
| `night_pass` | 主队到达出口且 `detect` 未爆表 | `exitZone`、`detectMax` | 惊动过阈被围 |

规划里补了「调开脱身」`breakaway` 和「行军消耗」`march`，这两类还没有接进代码。`night_pass` 先当作突击撕口的夜间参数。按节点的详细标注见 [目标类型](https://xingchen-ian.github.io/long-march-game/#/objective-types)。

### 数据形状（草案）

```json
{
  "type": "rear_guard",
  "params": { "durationSec": 90, "allySafeFlag": "column_clear" },
  "fail": { "if": "squadAlive==0" }
}
```

运行时只维护：`progress`（0–1 或秒数）、`failed`、`won`。  
事件卡 / 战术键只读写同一套状态，不另开关卡脚本语言。

**节点故事** = 选哪张事件卡文案；**程序目标** = 上表某一 type。一对多即可（同一 `rear_guard` 可挂湘江或草地不同文案）。

## 6.6 能力代价（战术键 · 学习《英雄连》）

战术键**不是常驻 Buff**，每次触发都记账：

| 代价 | 规则（占位数字，可调） |
|------|------------------------|
| 弹药 | 消耗选中单位 `loadout.ammo` 合计；不足则键禁用 |
| 冷却 | 键进入 `cooldownSec`（草案：掩护 8s / 尖刀 20s / 迂回 15s / 断后 一次行动限 1 次） |
| 暴露 | 短时提高被发现/被压制权重（tag `暴露` 若干秒） |

流程：行动前分配写入 loadout → 行动中按键扣 loadout → 不够就灰掉 → 冷却转好才能再按。  
与资源分配同一套账，不另开「技能点」货币。

## 6.7 掩体 / 压制 / 撤退（草案）

### 掩体
- 两档：`coverLight`（土坎/矮墙）、`coverHeavy`（厚墙/工事）
- 在掩体内：受击降伤；被压制时仍可还击（重掩体优于轻掩体）
- 离开掩体突击：移速/伤害↑，防御↓

### 压制
- 单位有 `suppression` 0–100（敌军也用同一套，见侧翼）
- 高压制：移速↓、还击↓；满值接近「钉住」
- 「掩护射击」主效果 = 对目标区域加压制，而不是纯扣血

### 撤退动词
- 新玩家动词：`retreat` → 指定安全点/队尾集合点
- 撤退中：受击降伤，但可能写入 `掉队`；未到点被打掉可能丢 `loadout` 一部分
- 可与 R2 联动：低士气单位更愿撤、不愿再冲

---

## 6.8 侧翼与毅力（敌军）

面向简化：单位有朝向；攻击来自侧后判定为 `flank`。

- **我方**：侧翼射击/突击伤害或压制加成（给「迂回」「尖刀」收益）
- **敌军**：被侧翼时 **毅力（resolve，复用 morale 字段即可）下降**；毅力过低 → 溃散/撤退/投降检定（易击溃）
- 不搞兵种克制表；侧翼 + 压制叠乘即可

草案阈值：侧翼命中 `morale -= 10`（下限 0）；`morale < 25` 时下一次受压有概率触发溃散事件卡。
