# long-march-game

长征主题游戏的书目与设计想法站点。与 [research-materials](https://xingchen-ian.github.io/research-materials/) 分开。

## 本地预览

```bash
python3 -m http.server 8000
```

打开 http://127.0.0.1:8000/

## 更新

- 书目：`data/books.md`
- 想法：`data/ideas.md`
- 导航：`data/index.json`

GitHub Pages：Settings → Pages → Deploy from branch → `main` / `(root)`。
