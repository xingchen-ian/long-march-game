# long-march-game

长征主题游戏的阅读书目、设计想法、故事框架、系统设计站点。与 [research-materials](https://xingchen-ian.github.io/research-materials/) 分开。

## 本地预览

```bash
python3 -m http.server 8000
```

打开 http://127.0.0.1:8000/

## 更新

- 书目：`data/books.md`
- 想法：`data/ideas.md`
- 故事框架：`data/story-framework.md`
- 目标类型草稿（不定稿）：`data/objective-types.md`
- 系统设计：`data/systems-spec.md`
- 系统结构图：`system-map/`（hash `#/system-map`）
- 武器调研草稿（不定稿）：`data/weapons.md`
- 敌军参考草稿（不定稿）：`data/enemies.md`
- 导航：`data/index.json`

## 图片

图存在本仓库 `images/`（按页分子目录：`weapons/`、`enemies/`、`story/`、`books/`、`diagrams/`），不外链。  
图注与文末「图片来源与许可」写作者、许可、Commons/文献链接。只收公有领域或明确自由许可；找不到可靠出处就不放。设计页可用本站自绘示意图。

GitHub Pages：Settings → Pages → Deploy from branch → `main` / `(root)`。
